# **App Name**: AtlasDesk

## Core Features:

- Project & Task Management: Core features for creating, tracking, and managing projects and associated tasks, including assignments and deadlines.
- Secure User Accounts: User registration, login, and secure session management with role-based access for different levels of users (e.g., admin, team member).
- Real-time Activity Feed: Displays recent updates and actions within the platform, such as task completions, project status changes, and team comments.
- Productivity Dashboard: Provides an overview of key metrics, pinned projects, task summaries, and analytic cards to help users track their progress and team velocity.
- Marketing & Public Pages: Includes a dynamic landing page, pricing plans, about section, contact form, and a simple blog for content delivery.
- AI Assistant for Workflow Optimization: An intelligent tool that analyzes user workflows to provide personalized task recommendations, suggest process improvements, or auto-generate initial project drafts.
- Admin Tools & Reports: Essential admin features including user management, role assignments, and basic reporting functionalities for platform oversight.

## Style Guidelines:

- Primary interactive color: A vibrant yet professional violet, Hex: #753BF5 (HSL: 252, 80%, 60%), for calls-to-action and key highlight elements, evoking creativity and focus.
- Background color: A very light, almost white off-white with a subtle cool undertone, Hex: #F6F5FA (HSL: 252, 20%, 97%), creating an expansive, clean, and minimal canvas.
- Accent color: A deep, muted professional blue, Hex: #2E6DA8 (HSL: 222, 60%, 45%), providing a complementary anchor for secondary informational elements and textual emphasis.
- Headline and Body text font: 'Inter' (sans-serif), chosen for its exceptional readability, modern aesthetic, and suitability for both crisp headlines and extensive body content across various UI elements.
- Icon set: Use 'Lucide React' for clear, concise, and modern line-art icons that complement the clean interface, ensuring consistency and intuitiveness.
- Styling details: Embrace 'rounded-2xl' for all major UI components and interactive elements, paired with 'soft shadows' to provide subtle depth and a premium, contemporary feel. Implement 'glassmorphism' strategically for select elevated UI components like modals or specific card elements to enhance modern visual appeal.
- Motion: Utilize 'Framer Motion' to implement smooth and engaging 'hover effects' on interactive components, subtle 'fade animations' for content transitions, seamless 'page transitions', and 'floating UI effects' for elements like pop-ups or notifications, ensuring a highly polished and dynamic user experience.
